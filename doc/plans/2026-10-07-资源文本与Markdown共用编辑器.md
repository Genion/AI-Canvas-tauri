# 资源文本与 Markdown 共用编辑器

状态：已实施，等待用户手动验收。用户已授权实现并提交；按用户要求不运行测试、构建、类型检查或浏览器验收。

## 范围与行为

资源库及最近使用中的 Markdown、文本点击进入大屏，左侧内容、右侧提示词和文件信息。Markdown 文件与 Markdown 节点大屏共用 UI Kit 的 `MarkdownEditor`，支持编辑、预览、分栏、格式工具、查找替换、撤销重做及字符/行数。保留现有安全渲染，不引入依赖；UI Kit 展示真实可编辑样例，颜色复用主题变量。

文件编辑保留内存草稿，主动保存至原文件；未保存关闭或重新载入要求明确放弃。读取限制为 2 MB 的 UTF-8 普通文本文件，拒绝符号链接、无效编码和二进制内容。保存保持 BOM 与 LF/CRLF，比较正文摘要，检测外部改动后拒绝覆盖；失败保留草稿。摘要校验与写入间仍存在外部进程竞争窗口，当前不保证跨进程原子比较写入。文件正文不新增持久化到数据库、日志或元数据。

Markdown 节点沿用编辑内容的既有持久化语义与防抖自动保存，已有文件持续覆写同一文件，新节点只创建一次文件。文件编辑同步当前项目的匹配节点前校验正文基线、项目与 canvas derivation guard，失效不覆盖画布。生成信息只按完整文件引用匹配唯一节点和成功历史；不按文件名猜测。
