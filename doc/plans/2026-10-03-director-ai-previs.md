# AI 镜头预演实施计划

**目标**：在同一个 `ai-director` 节点的菜单增加「AI 镜头预演」，通过已配置文本模型生成电影空间、简模、人物走位和摄影机运动，播放并输出截图/参考视频。

**架构**：新增 `ai-threejs` 运行时，使用独立、版本化的预演数据合同，不冒充 Blender Scene 或 `.blend`。模型只生成白名单 JSON；Three.js 负责几何、相机和关键帧呈现。场景保存在项目目录的不可变文件中，节点只存相对路径、SHA-256 和大小。写回经过项目、节点实例、运行时、场景引用和 canvas derivation guard 校验。

**技术栈**：现有 React、Three.js、文本生成、项目文件服务、Mediabunny；不新增依赖或原生命令。

## 已确认范围与步骤

1. 数据与生成：新增 `src/types/directorPrevis.ts`、`src/services/directorPrevisSchema.ts`、`directorPrevisService.ts`；补充 `types/index.ts` / `directorScene.ts` 和现有文本生成的取消信号。
2. 预演：新增 `directorPrevisRenderer.ts`、`components/director/DirectorPrevisViewport.tsx` / `DirectorPrevisDialog.tsx`；复用 ModalOverlay、ModelSelector、Select 和 UI Kit NumberStepper。支持摄影机/空间/俯视、轨迹、焦距/时长/关键帧调整、人物走位、播放/暂停/拖动及截图/MP4。
3. 节点与生命周期：修改 `DirectorDeskNode.tsx`、`directorRuntimeRegistry.ts` / `directorNodeOperationService.ts`；在 `store.history.ts` 补充可撤销的预演字段，在 `projectTransferService.ts` 补充项目引用。已有分镜改动保持不变。
4. 验证与文档：增加 schema、插值/渲染、生成/写回/存储定向测试；回归导演台、文本协议、历史及项目导入导出；更新导演台模块说明。

## 边界

- 首版提供简模与镜头预演，不声明真实物理模拟或自动避障。显示实际相机轨迹，允许用户调整关键帧。
- 摄影机和输出保持场景画幅；空间视图的辅助网格/摄影机图标/轨迹不进入输出。
- 生成、保存、导出失败保留上一场景，不自动重试模型请求；弹窗关闭取消其操作，项目/运行时/引用变化撤销在途写回。节点浮动输入框关闭后允许后台生成。运行时对象与控制器只在内存。
- 场景 revision 文件保留到项目删除，供撤销和复制节点共用；节点删除不单独回收场景文件。
- 主窗口弹窗承载此运行时。初始界面阶段未增加 Agent/MCP 生成工具；后续已确认的 MCP 扩展范围见下文。不声称与 Blender 无损转换。
- 3dviz-pro-max 仅用于已阅读的设计参考，未安装或执行外部脚本。

## MCP 直接生成与写入

- 已确认范围：修改 `src/services/chat/tools/directorTools.ts`、`tests/services/chat/directorTools.test.ts`、本计划与导演台模块文档。复用已有 MCP 发现/执行链、节点创建、运行时选择和预演服务，不新增依赖或原生命令。
- 外部大模型用 `director_get_previs_schema` 读取合同和示例，生成场景 JSON；查询或创建 `ai-director` 后，使用 `director_set_runtime` 选择 `ai-threejs`，再用 `director_set_previs_scene` 提交 `nodeId` 与 `sceneJson`。预演直接保存在指定导演台，双击即可播放和调整；应用内模型不会被额外调用。
- `director_get_previs_scene` 支持读回完整场景再修改，未保存返回 `null`。通过 MCP 瞬时内容返回有界完整 JSON，避免通用模型工具结果的 20000 字符截断。输入、场景正文和读取结果不进入持久化消息/任务摘要。
- 两项读工具为 `read`，写场景为 `canvas_write`，只开放给当前项目 MCP 控制会话，MCP 按自主模式执行；写入复用不可变项目文件、历史与派生守卫。格式不合法、取消、项目/实例/运行时/场景变化或存储失败均不发布过期引用，保留上一场景，不自动重试。截图/视频仍通过预演面板输出。
- 回滚：仅撤回三项 MCP 工具和 `director_set_runtime` 的 `ai-threejs` 参数入口；保留已经保存的预演文件、节点与面板能力。
- 自动验证通过：前端类型、测试类型、两项代码文件定向 ESLint；导演工具、MCP 控制、预演服务/合同、导演节点操作与运行时注册 6 个回归文件共 171 项测试；生产构建输出至系统临时目录，通过。差异检查及本阶段 4 个文本文件严格 UTF-8/乱码扫描通过。构建保留既有大分块和无效动态导入提示。
