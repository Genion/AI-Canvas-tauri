# v0.10.22 发布准备

日期：2026-10-31（Asia/Shanghai）。主题：**项目往返协作与三方合并**。以上一正式版 v0.10.21 为比较基准，源码起点 `6a8ff41c`。用户要求发布新版本，并追加复核项目导入导出；本轮在隔离工作区实施和验证，主工作区已有生成文件改动不覆盖。

## 范围与兼容性

包含项目 v3 导入更新、三方比较、冲突二选一、可选聊天文本与记忆追加、恢复点及过期写入保护；同时纳入人物参考图裁切与灰棚背景、分组尺寸及成员变更、模型身份一致性、资产接收端地址误判修复。具体边界和桌面验收见[导入更新专项](./2026-10-30-project-import-update-merge.md)。

数据库 v27、归档 v3，双方客户端应统一升级；旧 v1/v2 包继续兼容。独立图片编辑信息与资产索引附加元数据暂不迁移。恢复点占用额外磁盘空间；聊天只携带文本和来源，不恢复工具执行或源机器授权。Windows Legacy 不含 ONNX 和自动更新；macOS 仅 Apple Silicon，临时签名且未经公证。

## 发布前复核

- 导出按当前快照的有效文件清单打包，避免恢复点、已删除素材及失败导入残留外传；相同内容的多个逻辑文件仍保留。
- 旧包路径与对象键检查，移除本机文件投影、凭据和任务状态；再次读取原文件时核对预览记录及实际素材摘要，拒绝预览后被替换的包。
- 聊天导出与导入采用文本字段白名单；恢复点保存媒体 SHA-256 并在恢复前核对；项目改名后恢复仍保留当前素材目录。存储清理纳入恢复点引用，读取不完整时禁止清理。
- 合并拒绝孤立、重复归属和循环子实体，版本材料超限先拒绝再写基线。
- tar 扩展以 raw 模式预检体积，避免 GNU/PAX 元数据先于业务限制进入大块内存；展开预算读取实际条目长度。
- 修复发布门禁发现的 Select 回调类型、历史分组 ID 类型缩窄、普通预设变量填充；同步导入对话框入口用例并移除已无源码引用的翻译词条。
