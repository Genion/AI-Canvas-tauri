负责节点与连线、画布交互、项目切换、撤销/重做，以及画布内笔记和视频剪辑入口。

## 用户操作与显示调度

操作入口见[说明书：画布](../site/manual.html#canvas)、[图片连续预览与输出历史](../site/manual.html#image-sequence-preview)及[资产侧栏](../site/manual.html#asset-sidebar)。资产卡片只展示和操作原画布节点；文件索引与预览生命周期归[文件与存储](./文件与存储模块.md)。

- [MiniMapNodeStats.tsx](../src/components/canvas/MiniMapNodeStats.tsx) 统计 React Flow 当前展示的节点类型与总数，悬停小地图显示；不统计已隐藏的收纳节点，也不是文件数量。
- [OutputHistoryPanel.tsx](../src/components/OutputHistoryPanel.tsx) 可固定为右下角小窗；跳转不关闭面板，定位复用画布聚焦事件与回弹，搜索/导出/清空仍在完整面板。
- [useCanvasWheelZoom.ts](../src/hooks/useCanvasWheelZoom.ts) 统一滚轮输入。Figma 模式的普通鼠标滚轮直接缩放，macOS 普通鼠标经原生输入分流；触摸板保留平移与捏合，经典模式保留滚轮平移与 Ctrl+滚轮缩放。
- [canvasDisplayScheduler.ts](../src/services/canvasDisplayScheduler.ts) 统一节点细节、图片换源与恢复遮罩的显示任务。低于 16% 进入远景轻节点、达到 25% 才退出；交互结束 180ms 后渐进调度，每帧最多 4 项并检查同步回调预算。选中、编辑、播放、生成与错误状态保活，原图、端口身份和画布历史不变。该预算不是整体帧耗时或 FPS 保证。
- 同一显示档位保持已展示图片，换档先准备并解码再切换，过期项目/来源回调失效；磁盘缓存和内存租约复用既有服务。详见[当前性能实施与实测限制](./plans/2026-09-09-canvas-interaction-performance.md)。

## 关键边界

- 分组与多选批量生成共用 `utils/batchExecute.ts`。工作流节点（带 `workflowId`）按界面展示编号数值升序串行执行，生成及结果保存结束后才启动下一项；缺少编号的旧节点排在最后并保留原顺序。同批普通节点仍按连线依赖串行、独立节点并发。编号顺序与依赖构成环时，环内工作流以编号顺序为准；单项失败后继续，不自动重试。队列仅约束本次批量调用，不合并其他批次或手动生成。回归入口：`tests/services/batchExecute.test.ts`；本次与音频及节点交互共 61 项回归、前端/测试类型与定向 ESLint 通过，未执行真实工作流生成。定向 Vitest 须排除 `.planning/**` 的旧源码副本，避免同名用例混入。回滚仅撤销调度及对应测试修改，无持久化迁移。

- 画布空白处右键可创建空白宫格分镜：支持 4/9/16/25 格预设、可视行列选择与 1–20 行、1–20 列输入。新宫格仍使用 `ai-storyboard` 的行列和空格数据，空格可接收拖入的图片；已有图片裁切生成的宫格保持原有语义。宫格创建和填格都进入画布历史。

- 展开分组的内部空白区透传画布事件，支持右键新建和连线拖放新建；标题栏负责整组拖动与管理，边框保留缩放。单节点创建按中心位置加入展开分组，拖入空节点与有内容节点使用同一套实际几何判定，父节点排序在子节点之前；节点、连线与成员关系共用操作历史，折叠分组不自动接收新建节点。

- 图片节点生成历史卡片支持将项目内普通媒体文件移入系统回收站并删除记录，也可仅删除记录；文件缺失时清理记录，仍被当前画布、对话或其他历史引用时拒绝回收。远程链接不发起服务器删除，项目切换后旧操作失效，回收失败保留记录。

- 媒体节点复制先准备独立文件再插入节点；失败不退回共享本地文件。分组归档、解组与改名真正移动文件，提交历史及资产引用迁移并保存后再清理源文件和空目录；失败保留源文件并记录待恢复迁移，旧共享节点先拆分。范围、回滚与验证见[独立媒体复制](./plans/2026-09-17-independent-media-copy.md)。

- 共享状态通过 Store Action 修改；画布写入纳入历史，批量操作只提交一次快照。
- 框选至少两个可连接节点后，选区右侧显示与普通节点端口同样外观的临时批量连接手柄。拖拽预览由每个源节点的右侧端口分别出线，并在鼠标位置汇合；拖拽开始锁定源节点与项目。连接已有标准节点时一次创建多条普通入边，重复边跳过且只提交一次历史；拖到空白处可一次创建目标与全部连线。手柄不作为画布节点持久化，插件类型端口、分组和笔记不参与。下游沿用各节点的现有普通连线输入语义；文本生成仍以提示词中的 `@` 引用为准。
- 图片节点全屏预览通过 `CanvasImagePreview.tsx` 按展示编号升序浏览当前项目内有图的生成/源图片节点，跳过空节点和角色库收纳节点；两侧按钮与 ↑/↓（兼容 ←/→）切换，首尾不循环。切换复位缩放，浏览不修改画布选择和历史；关闭后释放预览，项目切换或当前图片节点消失时退出。
- 音频节点双击打开 `CanvasAudioPreview.tsx` 全屏播放器，支持播放/暂停、进度拖动、音量/静音及真实 Web Audio 频谱。当前项目有音频的生成/源音频节点按展示编号数值升序切歌，跳过空节点和角色库收纳节点，首尾不循环；播放结束自动进入下一曲，末曲停止。方向键切歌，滑块保留原生键盘操作；浏览不修改画布选择或历史。节点内播放交接到全屏，关闭、切歌、项目切换和当前来源失效时释放旧播放器及分析资源；跨域或分析能力不可用时使用独立普通媒体元素保留基础播放。详见[音频播放器计划](./plans/2026-09-16-audio-fullscreen/task_plan.md)。
- 图片节点在画布内使用按屏幕尺寸分档的项目磁盘缩略图与有界内存预览；三平台统一项目数据目录下的 `.thumbnail`，Windows 额外设置隐藏属性。高清查看和编辑仍使用原图；连接按钮缩放补偿由画布统一维护。资源队列、失效与回收边界见[大画布交互性能优化](./plans/2026-09-09-canvas-interaction-performance.md)。
- 节点工具条首次可见才挂载，随后隐藏时保留编辑和弹窗状态。视频待机使用共享内存封面，单选或实际操作时加载播放器，暂停且不再单选时释放；封面生成串行并服从画布交互暂停。历史面板隐藏时停止整图差异计算；完整节点、选择、连线和历史语义保持。
- 异步结果不能写入已切换的项目；笔记和普通节点复用选择、历史与持久化语义。
- MCP 剪辑只绑定当前项目的素材节点，工程更新比较完整版本；人工剪辑窗口打开时拒绝后台修改。输出最多 1080p 等像素面积、60 fps、300 秒；支持主轨、叠加文字、转场和音量包络。后台导出复用合成器，写盘前后复核工程、来源与画布，成功只提交一次历史；抽帧图像仅作为瞬时 MCP 内容返回。接口与验收边界见 [MCP 视频制作](./plans/2026-09-11-mcp-video-production/task_plan.md)。
- 分镜表使用稳定镜头 ID；局部修改保留画面绑定，补图绑定真实图片节点。镜头行和列纳入结构化撤销快照。分镜表与宫格分镜节点职责独立，范围及验收见[本集分镜制作与助手联动](./plans/2026-09-08-shotlist-production.md)。
- 补图取消立即停止本地等待并保留完成项，参数改动使排队/在途结果失效；再次补图只处理仍无绑定的镜头。助手读取镜头按 JSON 大小分页，须按返回偏移续读完整正文。
- 分镜表提供整表诊断与单镜优化的助手草稿入口，发送时读取最新镜头；单镜请求使用稳定 ID，并沿用会话模式与写入策略。
- 新建分镜保存本集与来源快照节点引用，可检查当前剧本差异并选择要复核的镜头；创建来源持续保留，缺失来源时不猜测。差异比较只提示文本变化，助手读取完整正文后再判断如何修改。
- 节点界面调用模型/文件服务，具体 Provider 请求归[模型与生成](./模型与生成模块.md)，项目落盘归[文件与存储](./文件与存储模块.md)。
- 全景查看器源码由项目维护，仅使用固定版本 `pannellum` 渲染依赖；构建不再下载 XiaoLuo-Panorama 仓库。全景 CSS 经 `src/index.css` 随主入口加载，JS 继续按需加载。截图落盘、节点创建与项目切换防护仍由 `PanoramaNode` 负责。
- 全景源码保留 Apache-2.0 来源说明，许可证随 `public/licenses/` 分发；关闭查看器会取消待处理截图，销毁渲染实例并断开尺寸监听。迁移范围、验收与回滚见[全景源码内置](./plans/2026-09-07-panorama-internalization.md)。
